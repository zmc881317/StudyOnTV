# 玩法设置

共用一套题库和规则格式，分别提供 Android TV 包与手机 / 平板包。家长通过局域网面板设置玩法，孩子使用遥控器或触屏答题。

## 三种玩法

| 玩法 | 完成条件 | 时长奖励 |
|---|---|---|
| 按组闯关 | 做完指定题量，达到正确率，并完成待加练题 | 按组奖励或按答对题目的星级累计 |
| 连续答对 | 连续答对指定题量，并完成待加练题；答错重新计连续数 | 按组奖励，或本次连续答对题目的星级奖励 |
| 自由练习 | 持续出题，无固定结束点 | 不奖励使用时长；可以偿还加练池 |

普通任务的规则在开始时固定。已答题的任务在下一组使用新规则；尚未答第一题时可直接使用新规则。切换玩法会开始对应的新任务，加练池不清零。

## 小学 / 初中 学段

孩子首次答题时选择小学或初中，之后按学段抽题：小学生只抽小学题和通用题，初中生只抽初中题和通用题。初中学习页标题显示「初中」，使用蓝色主题。切换学段需要家长密码验证（设备上的家长入口「切换学段」，或 `PUT /api/stage`）。切换时，如当前任务还没答题会立即换成新学段的题；已经答了一部分的任务继续完成，后续题目按新学段抽取。

## 加练池

家长可设置「每累计答错 N 题，增加 M 道加练题」，也可以关闭新增加练。

- 每次答错立即保存，达到阈值就增加待加练题，错误累计数也会保留。
- 达到普通任务的通过条件后，继续完成池里的加练题；每答对一道加练题，待做数量减一。
- 加练答错仍计入错误累计，可能继续增加待做题数。
- 加练题不额外奖励时长。通过任务并清完加练池后才发放奖励。
- 池子跨天保留，退出、强杀和重启不会清除。关闭新增加练后，现有待做题仍需完成。

## 星级奖励

每道题可设 1–5 星。家长开启「按星级奖励时长」，分别设置每种星级答对一题奖励多少分钟，支持小数。

例如：1 星奖励 1 分钟，3 星奖励 3 分钟，5 星奖励 5 分钟。一组任务里答对 1 星和 3 星各一道，完成通过条件后获得 4 分钟。加练题不计奖励。连续答对玩法只累计当前连续段的奖励，答错会重置该段。

关闭星级奖励时，仍按「每组解锁分钟」发放。所有奖励受每日上限约束，重复提交同一答案不会重复计数或领取。

## 实际使用时间

解锁时只增加可用余额。切换到其他受控应用且屏幕亮着时，才扣减余额并记录实际使用；答题、家长验证、桌面、锁屏和熄屏不扣。余额与实际使用记录保存在本地 SQLite，重启后不会重新赠送时间。

时段支持跨午夜，「全天」是独立开关。时段用途可选：

- **仅时段内可用**：时段外不可使用，提示下次可用时间；时段内仍须答题解锁，并遵守每日额度。
- **仅时段内需要答题**：时段内答题、计时与限额生效；时段外为自由使用，不扣余额，也不因待查看的批改结果拦截。适合白天家人正常看电视，17:00–21:00 再要求孩子答题。

每日任务数量和使用额度在设备本地零点重置，加练池保留。

## 间隔重复复习

在管理面板「规则 → 加练与复习」中打开「间隔重复复习」，默认关闭。

启用后优先抽取到期题，再补新题；当前没有到期题或新题时，按最近到期顺序补充练习。使用基于 SM-2 的简化算法：初次答对后约一天再复习，再次答对约六天，之后随熟练度逐步延长；答错后约十分钟进入待复习。题库较少时可能重复抽到尚未到期的题，以便继续完成任务。

客观题按答对与答错更新熟练度，主观题在家长、Agent 或 AI 评分后更新。关闭开关只改变抽题方式，已学习进度仍会保留，跨天与重启不清零。

## 平板公式与输入

题干、选项和参考答案可写 LaTeX 公式。公式库与字体随 APK 提供，遇到公式才加载。手机 / 平板包支持语音转文字与手写图片；语音识别由系统服务提供，能否离线取决于设备已安装的服务。TV 使用系统输入法，语音能力取决于电视输入法，不含独立手写模块。

主观题与手写答案保存在待批队列。等待批改时不发放奖励，作答和加练池不丢失；家长或 Agent 可以评分，也可配置 AI API 自动批改。文字模型不能处理手写图片时保留给家长或图像模型。

## 管理入口

首次使用设置 6–64 位管理密码。之后连续点击应用标题 5 次，或在被控界面连续短按遥控器「上」5 次，输入密码可重新打开连接页。

连接页二维码仅包含面板地址。家长打开面板仍须输入管理密码，API 也必须验证；旧版 6 位访问码不再使用。修改密码会立即使所有管理令牌失效。

无障碍与悬浮窗按需开启，未开启也可进入学习和家长设置。悬浮窗配合使用情况访问，可以识别应用使用并在到时间后显示学习页；只开启悬浮窗时，按离开学习页后的亮屏时间计时。无障碍可帮助及时识别应用切换，不是必选项。

「管控期间拦截系统设置」默认开启，在有识别与拦截权限时生效，即使还有可用余额也会保护系统设置；设备上的家长验证可临时放行。「仅时段内需要答题」模式的自由时段不拦截设置。支持设备管理员的系统还可另行授权防卸载，家长可解除授权；这不属于设备所有者级锁定。

学习页出现时先发送媒体暂停并请求音频焦点；播放器继续输出时静音兜底。离开学习拦截或进入自由时段后恢复原静音状态，原先未静音时恢复媒体音量。不同电视、直播和视频应用的表现需以实机为准。

系统强行停止应用、撤销权限或卸载会影响管控；厂商后台限制、开机广播与遥控器待机差异见[安装指南](./install.md)。
